# Webベース個人情報収集システム

> **注記**
>
> 本プロジェクトは、英語圏の大学の環境で開発したものです。コード内のコメントはもともと英語で記述されており、日本語への翻訳には機械翻訳を用いています。翻訳後の内容については、自身で確認・修正を行っています。

## 概要

HTML、CSS、JavaScript で実装した静的ウェブアプリケーションです。フォームへの入力値をクライアント側で検証し、外部サーバーへ送信します。フロントエンドの入力検証ロジックの分離設計と、バニラ JavaScript による DOM 操作を扱っています。

## 使用技術

- HTML5 / CSS3
- JavaScript（フレームワーク不使用）

## 必要な環境

- モダンなウェブブラウザ（Chrome、Firefox、Edge など）
- フォーム送信の動作確認にはインターネット接続が必要

ビルドツール（npm、webpack など）は不要です。

## 実行方法

### 方法 1: ブラウザで直接開く

`index.html` をブラウザで開きます。

### 方法 2: ローカル HTTP サーバーを使用

プロジェクトルートで以下を実行し、ブラウザで `http://localhost:8080/` を開きます。

```bat
python -m http.server 8080
```

## ファイル構成

| ファイル / ディレクトリ | 説明 |
|---|---|
| `index.html` | フォーム UI |
| `styles.css` | スタイルシート |
| `Scripts/` | 入力検証用 JavaScript |

## 補足

- フォームは **GET** メソッドで `http://www.it.murdoch.edu.au/cgi-bin/reply1.pl` へ送信されます
- 送信動作の確認には、送信先サーバーへアクセスできるネットワーク環境が必要です
